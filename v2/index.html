Spatial Test Repository

Build and run spatial cognition batteries

Pick from a catalog of real spatial-cognition tests, configure exactly which items and settings each one uses, and generate a single link that runs the whole battery for a participant. Log in to get started.

SpatialTestRepository

Overview

What you can do here

Assemble a battery from the test catalog, configure each test's items and settings, then send participants a single link that runs everything in order.

01
Select tests

Browse the catalog and add one or more tests to a battery.

02
Configure

Choose specific items, timing, randomization, and scoring per test.

03
Generate a link

One link runs the whole battery for a participant, in order.

04
Export data

Track participant counts and download results as CSV from Datasets.
